# 🍽️ AR Interactive Restaurant Menu & Business Card

An augmented reality application built with Unity and Vuforia that transforms a static restaurant poster (or business card) into an interactive 3D digital experience. 

*(**Note to Self:** Replace this line with a GIF or YouTube link of you actually scanning the poster with your phone. Visuals are #1 for AR portfolios!)*

## ✨ Core Features
* **Vuforia Image Tracking:** Robust marker-based tracking using high-contrast restaurant imagery.
* **World Space UI:** Interactive floating menus and buttons rendered in 3D space anchored to the real-world target.
* **Dynamic Interactions:** Touch-based raycasting allowing users to click physical-looking digital buttons to view menu items or link to social media.
* **Android Optimized:** Built and compiled for mobile deployment.

## 🛠️ Tech Stack
* **Game Engine:** Unity (2022.3 LTS)
* **AR SDK:** Vuforia Engine (11.4.4)
* **Language:** C#
* **Version Control:** Git & Git LFS (Large File Storage)
